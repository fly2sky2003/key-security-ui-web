# 实测演示数据（5 组）

来源：`DATA/` 中 2026-09-15 / 09-17 / 10-08 的实测采集，每组一次会话（UE / PUSCH / EVE 三方）。

## CSV 结构（原始文件，无表头）

每行 8 个表头字段 + 特征值：

| 列 | 含义 | 例 |
|---|---|---|
| 0 | 标记位 | `PDSCH DMRS` / `PUSCH DMRS` |
| 1 | RNTI（16 bit） | 65373 |
| 2 | PCI（≤1007） | 615 |
| 3 | 时间戳 | `10:13:16` |
| 4 | 帧（0–1023） | 185 |
| 5 | 时隙（0–17） | 0 |
| 6 | 符号（DMRS 取 2 / 7 / 11） | 2 |
| 7 | RB 数 | 48 |
| 8+ | 特征值 | 每 RB 3 个复数值，写成 `I,Q,I,Q`（后两个与前两个重复） |

每行复数值个数 = RB × 3（48 RB → 144 点）。

## 做了哪些处理

- **按秒聚合**：原始文件每秒 12–70 行，网页本来也按秒取幅度均值；这里把均值提前算好，每个时刻一行
- **频域点**：保留全部 144 点（48 RB × 3），每点写 `I,Q,I,Q`
- **时间**：完整会话，未截断
- **密钥**：每组取前 120 行（61,440 bit）

5 组共约 9 MB。
