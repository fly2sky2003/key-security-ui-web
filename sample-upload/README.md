# 实测演示数据（5 组）

来源：`DATA/` 中 2026-09-15 / 09-17 / 10-08 的实测采集，每组一次会话（UE / PUSCH / EVE 三方）。

## 做了哪些处理

原始数据（48 子载波、每秒数十行）完整保留在 `DATA/`，这里的副本只做了聚合，没有截断时间、没有裁子载波：

- **按秒聚合**：原始文件每秒有 12–70 行，网页里本来也会按秒取幅度均值；这里把均值提前算好，每个时刻写成一行。数值与网页读取原始文件的结果一致。
- **子载波**：48 个全部保留，每个子载波写 4 个数 `I,Q,I,Q`（I = 该秒幅度均值，Q = 0），与原始格式相同。
- **密钥**：每组取前 120 行（61,440 bit），三方同步截取。

这样 5 组共约 3.3 MB，网页载入快，观测预览里的子载波波形也是完整的 48 点。
